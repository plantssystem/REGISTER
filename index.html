PROPHETIQUE

Prophet-5「MIDIA」C3 の1音から生まれる、5音ポリのジェネレーティブ・シーケンサー
音が出ます。音量にご注意ください

Controls

Keyboard

A B X Y
キーを C / A / F / G に切り替え
↑ ↓
項目を選ぶ
← →
値を変える(押しっぱなしで加速)
SPACE
CTRL。単独で押すと曲頭から。押しながら ← → でページ切替(MAIN / MIX / ORDER)、押しながら A B X Y でトラック1〜4のミュート

スマホでは、CTRL を押したまま別の指でボタンを押します。

Parameters

NOTE%各音が実際に鳴る確率
DIRECT音の進行方向。FWD=原曲順、REV=逆順
P4 8THパート4を8分音符で打ち直す割合
MUTATE原曲への忠実さ。0%で原曲どおり
SCALE音階に寄せる(M.PENTA、DORIAN、HIRAJO ほか)
AUTO1/2/4/8小節ごとにキーを自動で変える
FILT / VERBローパス・フィルターとリバーブ
MIXトラックごとの VOL / PAN / TRP(移調)
ORDER音の高さを ORG(原曲順) / SCR(並べ替え) / RND(ランダム) から取る割合
